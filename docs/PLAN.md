# PLAN · world.execute(me);「程序执行世界」总体方案 v4（终校版）

> 依据：任务书 v1、v2、v3、v4（优先级最高）。事实数据以本地资料为准。
> 状态：待确认。确认前不写渲染代码。

## 1. 主题与情感落点

程序把爱当作宇宙来执行：老电脑开机 → 键入 `world.execute(me);` → 程序运行一个宇宙
（几何→物理→量子→分形→黑洞→大爆炸）→ 收束成一颗心脏 → 程序正常退出、关机。
情感弧线 = 宇宙的诞生、成长、失落、坍缩、爆发、归心。不是疯狂、不是毁灭。
全片唯一最亮帧 = S14 结尾「公式写全 + 心形闭合 + 金光线全亮」那一帧
（唱到 you are free / I am trapped），静止 ≥1.2s，是全片情感落点。

## 2. 三种画面模式（切换必须有剧情原因）

| 模式 | 是什么 | 用在哪 |
|---|---|---|
| 终端界面 | 老电脑/操作系统的窗口世界：BIOS 自检、`>>>` 提示符、命令键入、进度条、警告弹窗、嵌套窗口、十六进制转储 | S01、S05（监视窗矩阵）、S07、S10、S14（前半）、S15（命令卡）、S16 |
| 数据空间 | 程序运行出的宇宙：粒子、场、网格、分形、时空；2D 公式平贴与 3D 挤出砸入 | S02、S03、S04、S06（档案卡化）、S08、S09、S11、S13、S14（后半）、S15 |
| 纯代码 | 代码清单 + 终端输出，无界面装饰 | S12 EXECUTION 段专用 |

切换动机（每处写在 STORYBOARD）：S01→S02 命令执行进入宇宙；S05→S06 供给具象成档案卡；
S09→S10 崩溃弹回界面；S12 纯代码=十二声执行；S13 重启回数据空间；S14 段内转换
（动机=公式写全的瞬间，窗外宇宙与公式重合）；S15 数据空间+界面命令卡；S16 关机。

### 3.2 全局递进量（4.1.6）

- **宇宙演化度 u(t)**：0→1 单调函数（锚点=16 段边界），驱动：背景密度、网格维度
  （2D→3D 透视）、粒子强度、运动幅度、代码语言数量。
- **心搏强度 h(t)**：0 起步，S15 起随 ECG 按拍跳，提示音 207.873s 达到 1，驱动金与
  心脏亮度的唯一来源。
- 两条量的锚点都在 config.json → progression，代码只读。

### 3.3 字体与排版

等宽 Consolas=系统/代码/日志/HUD；衬线斜体=公式（真公式、规范排版）；
无衬线=界面文案（用雅黑可替）。关键词全大写+着色=乐句视觉高点；正文句放固定字幕带，
同段内位置字号不变。歌词文字只经时间轴文件取，不写进渲染代码。

字幕带全局规则（全片唯一，各段不重复）：英文逐词点亮（打字 ≤0.25s + 0.08s flicker +
关键词青/金着色）+ 中文整行翻译第二行（系统雅黑），全片位置固定。

### 3.4 CRT 与故障美学

扫描线、轻微桶形暗角、荧光余辉、受控色散、白横条闪烁（锁拍、受闪光预算约束）。
故障只出现在剧情指认处（S10 崩溃、S12 EXECUTION、S13 大爆炸），其余段画面干净。

### 3.5 角色系统（鲸鱼娘=程序本人）

她是老电脑里运行宇宙的那个进程的人格化：歌词里的「我」就是她。素材=DeepSeek 鲸鱼娘
（女仆版，CC BY-NC-SA 4.0），从 `world-execute-me-dsh-pv` 复制 `maid-left.webp` 与
`expressions/` 8 套到本工程 `assets/char/`，随附上游 NOTICE 与署名链（溟月 © 上善无形 /
女仆版 ZipZipPipe / 立绘 dsh-deep-whale（Small-tailqwq）/ 表情 dsh-whale-galgame）。

三种形态，切换必须有剧情动机：
1. 界面形态（立绘）：终端界面模式中的人格窗口；表情只用 8 套原图 + 轻度处理
   （裁切/缩放/调色/像素化），禁止画脸/画表情/改瞳孔/裂口/红泪/血红描边。
2. 数据形态（代码生成）：数据空间中她由本片可视化系统生成——点阵侧脸、傅里叶本轮
   轮廓、ASCII 字符鲸鱼（学 dsh shot_whale）、波函数云、星图核心、数据流双螺旋。
   数据空间段渲染代码禁止引用立绘资源（静态检查）。
3. 纯代码形态：S12 十二轮她不出现；唯一例外=最后一声（161.88s）四个字母块背后
   各闪现一帧她的点阵侧脸。

两种形态是同一存在的两种投影：进入宇宙=进入她的内心；回到界面=回到外壳。
她不得固定位置：`character.position_per_section`（16 段位置表）集中定义，相邻段位置/
景别不重复（audit 校验）。她的每项运动进该段运动驱动表（词 onset/拍点/进程状态/游标
事件），禁止无驱动抖动；静止段她靠静态细节成立。

## 4. 音乐与歌词技术规范

1. 拍点网格：`tools/analyze_audio.py`（librosa 起音检测+节拍追踪）对本机 mp3 实测 →
   `data/beats.json`；切点一律 B(小节)/Bt(拍) 函数化，禁止裸数字。前轮实测 129BPM
   仅作先验，不硬编码。
2. 词级时间轴：复用 `word_timeline.json`（同曲、零点=解码首样本）；与本机 mp3 互相关
   核验偏移（实测约 -51ms）→ `config.json → timing.offset` 单点管理。
3. 字幕带：英文逐词点亮（打字 ≤0.25s + 0.08s flicker + 关键词着色，学 words.py）；
   中文整行翻译第二行（系统雅黑，字体版权见 §10）；位置全片固定。
4. 关键时间（全部移入 src/cues.py，每项一行：名称、秒数、来源=实测/初值）：
   L97 词 onset=205.37（实测）与其三音节（初值，音频分析完成前不得当实测引用）；
   硬静默起点 207.08；提示音 207.873=心脏点亮；片长 211.9（5086 帧@24fps）。
5. 结构锚点：歌词分段以 word_timeline 为分镜硬边界（见 STORYBOARD）。

## 5. 真实计算清单（data/facts.py 集中定义，注明来源）

- S03 几何：单位圆参数化 + 正弦曲线（真实采样）+ 4D 超立方体旋转投影（4×4 旋转矩阵）。
- S04 电磁：AC/DC 波形（sin 与常量电平）+ 色散（波长→RGB 偏移）。
- S05 模拟：洛伦兹吸引子（σ=10,ρ=28,β=8/3，RK4 积分）+ 双摆（欧拉法）。
- S08 共振：傅里叶本轮（方波/心形轮廓傅里叶系数）逐阶合成。
- S11 坍缩：一维波函数（自由粒子高斯波包演化）+ 曼德博集（numpy 分块计算、降采样放大）。
- S12 十二幕宇宙史（正序）：大爆炸、暴涨、夸克胶子、核合成、复合、第一束光、恒星、
   超新星、中子星、黑洞、暗能量、热寂——每幕一个参数化图形（膨胀率、温度、元素丰度
   数字）。十二声 = 宇宙一生被循环执行十二次，第 k 轮以第 k 个阶段为特写放大。
- S14 爱的代数式：(x²+y²−1)³−x²y³=0 逐点描出（射线二分求根，同 lyric-mv heartRadius）。
- 常数：c=299792458 m/s、ħ=1.054571817e-34 J·s、G=6.67430e-11。
- 禁止"看起来像"的假图形；每个图形在 facts.py 有来源注释。

## 6. 复杂度宪法落地（对应任务书 §4）

- 每帧 ≥8 个命名信息层（层名=STORYBOARD 层清单），全片平均 ≥9，S12 高潮 ≥12；
  每层有独立内容/独立运动/独立驱动源（层清单+运动驱动表）。
- 常驻框架层 = CRT 底与竖纹、频谱细带、字幕带、日志窗框；不计入 8 层底线；
  每帧 8 层中至少 6 层必须是本段专用动态内容层；tools/audit.py 分别统计、分别报告。
- 转场只做 reflow/zoom/pan/spin/crt + 冲击位移（≤6 帧），每个有理由注释。
- 运动规则：降帧只用于单向推进；光是棘轮；冲击 ≤6 帧单向位移且锁拍；
  静止镜头靠静态内容密度成立（不许轻微抖动假装运动）。
- 布局多样性：本片布局枚举 `boot / shell / grid2d / grid3d / cardstack / desk / plate /
  code / raw / crt`；`tools/audit.py` 按本枚举检查相邻段布局不重复（EXECUTION 十二轮除外）。
- 红色=错误/临界，只在其语义段受控出现；错误红首次出现锁定 L64「illegal arguments」
  （时间进 cues.py 实测标注），此前一律灰白/黑。
- 角色层计入「本段专用动态内容层」：界面段=立绘窗层，数据空间段=数据形态层；
  每段动态层仍 ≥6，总层数相应增加（不挤占常驻框架名额，也不被常驻层挤掉）。

## 7. 工程架构与确定性

```
world-execute-me-universe/
  config.json          一切旋钮：palettes / section_ground / progression / timing.offset /
                       safety.flash_budget / fonts / resolution /
                       character.enabled=true / character.assets_dir /
                       character.expressions（8 套映射）/ character.position_per_section
                       （16 段位置表）/ character.silhouette_seed（数据形态种子，确定性）
  data/
    beats.json         拍点网格（tools/analyze_audio.py 实测）
    lyric_timing.json  word_timeline.json 的复制（词级 onset）
    audio_features.json 频谱/低频能量/onset（analyze_audio.py 输出）
    facts.py           公式/常数/宇宙阶段/多语言代码片段（注明来源）
  src/
    cues.py            全部非网格时间（每项一行：名称、秒数、来源）
    engine/            camera.py（视口/推拉/对象匹配机位）· transitions.py ·
                       draw.py（图元/文本）· post.py（扫描线/暗角/余辉/色散）
    components/        terminal.py · code.py · formula.py · hud.py · subtitle.py ·
                       fractal.py · dialogs.py · spectrum.py
    scenes/            sec_01_boot.py … sec_16_shutdown.py（一段一模块）
  film.py              渲染主入口：stills / render(分段多进程进 ffmpeg) / audit
  tools/               analyze_audio.py · audit.py · check_flash.py · luma.py ·
                       sheets.py · compare.py · verify.py
  docs/                LEARNED / PLAN / STORYBOARD / PROGRESS / KIT
  assets/char/         鲸鱼娘立绘与 8 套表情 + 上游 NOTICE（CC BY-NC-SA 4.0）
  input/               （歌曲，gitignore）
  out/                 （gitignore）
```

确定性：每帧只由 t 决定；不存跨帧状态；随机数全部 `prng(seed,t)`；同参数两次渲染
逐字节一致（verify.py 抽查）。模块化：段间只经镜头表编排，禁止段间改函数。
性能：单帧 <500ms；numpy 向量化；静态层预渲染缓存；分形降采样+放大；
多进程分段渲染入 ffmpeg 管道（学 v2.py worker）。

## 8. 验证协议（每步客观数字）

1. 静帧卡片（每段做完）：`film.py --stills <时间点>` 检视切点后首帧、关键词落地帧、
   每个转场；标准="不看字能说出画面在讲什么"。
2. 密度审计 `tools/audit.py`：每 10s 抽 1 帧+每切点后首帧，报告命名层数（≥8）、
   稳定内容密度（不低于 dsh TUI 参考）、可溯源运动像素 ≥95%、无驱动抖动 <1%、
   9 宫格动态覆盖 ≥70%。
3. 闪光安全 `tools/check_flash.py`（预算：任意 1 秒亮度往返 ≤3 次；大饱和红不快移；
   花屏图案保持 ≥6 帧）；片头与 EXECUTION 单独先测，数字写进 README。
4. 同步：提示音 207.873、终曲词 205.37、逐词 onset 与音频互相关校验并报偏移数。
5. 回归：改共用组件前后出同时间网格缩图逐格比对，非目标差异必须为 0。
6. 成片：解码全片 exit 0；分辨率/帧率/时长核验；静音 4K 同检。
