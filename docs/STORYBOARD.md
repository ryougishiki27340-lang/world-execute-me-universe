# STORYBOARD · 16 段全片分镜 v4（终校版）

> 骨架=任务书 v1 §7 + v2/v3 修订 + v4 终校；歌词时间以 `data/lyric_timing.json` 为
> 硬边界；切点一律 B(小节)/Bt(拍)；非网格时间只出现在 `src/cues.py`（文档引用写
> 「见 cues.py」），来源标注实测/初值，音频分析完成前不得当实测引用。

## 全局规则

- 三种画面模式：终端界面 / 数据空间 / 纯代码。段内允许转换（S05、S14 各一次），
  每次转换必须写动机。
- 本片布局枚举：`boot / shell / grid2d / grid3d / cardstack / desk / plate / code / raw / crt`。
  相邻段布局不得重复（EXECUTION 十二轮除外），`tools/audit.py` 按本枚举校验。
- 常驻框架层 = CRT 底与竖纹、频谱细带、字幕带、日志窗框。它们不计入每帧 8 层底线；
  每帧 8 层中至少 6 层必须是本段专用动态内容层；角色层计入动态内容层。
- 字幕带（全局唯一规则，各段不重复）：英文逐词点亮（打字 ≤0.25s + 0.08s flicker +
  关键词青/金着色）+ 中文整行翻译第二行（系统雅黑），全片位置固定。
- 「你」= 白色游标 + 键入文本 + 回车 + 在线状态；游标只碰控件，不碰其他。
  四段必现：S01 键入命令、S05 游标旁观她按下 EXECUTE、S09 游标淡出（你走了）、
  S14 游标沿切线离开。
- 白闪预算：全片 ≤8 次、1 帧、锚定重拍；副歌重拍轻闪强度 ≤0.3 且全部计入
  「任意 1 秒亮度往返 ≤3 次」预算（tools/check_flash.py 实测，数字写 README）。
- 层清单每层标注驱动源：词 onset / 拍点 / 低频能量 / 高频 onset / 进程状态 / 单向时间演化。

## 角色总则（她=程序本人，两种形态同一存在）

- 界面形态=立绘（`assets/char/`：maid-left + 8 套表情）；数据形态=本片可视化系统生成
  （点阵侧脸/傅里叶本轮轮廓/ASCII 字符鲸鱼/波函数云/星图核心/数据流双螺旋）；
  数据空间段渲染代码禁止引用立绘资源（静态检查）。
- 表情只用 8 套原图 + 轻度处理（裁切/缩放/调色/像素化）；禁止画脸、改瞳孔、裂口、
  红泪、血红描边（旧作病娇处理一律禁止）。
- 每段写清：形态/位置/景别/表情/动作/驱动源；相邻段位置不重复（audit 增角色位置
  多样性检查）。运动全部进驱动表，静止段靠静态细节成立。
- 情绪沿宇宙弧线走，落点=成全与归心（S14 你自由、S15 心脏、S16 正常退出）。
